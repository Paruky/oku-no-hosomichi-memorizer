# 暗唱ラボ — おくのほそ道

松尾芭蕉『おくのほそ道』を声に出して覚えるための、軽量な日本語Webアプリです。

## 機能

- 「、」「。」ごとに区切った一節ずつの暗唱練習
- 本文中の括弧を使ったルビ表示
- 答えを隠して声に出す練習と自己評価
- 全文をルビ付きで読めるページ
- 苦手な節を集める復習リスト
- 本文を隠して挑戦する4分タイマー
- 学習進捗をブラウザ内に保存
- スマートフォン・PCに対応

## 使い方

`index.html` をブラウザで開くか、GitHub Pagesで公開されたページを利用してください。ビルドやサーバーは不要です。

学習記録はブラウザのローカルストレージに保存されます。別の端末やブラウザとは共有されません。
